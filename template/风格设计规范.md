# 5.0 质感卡片风格 · Remotion 设计规范（4.5 版）

> 写给 Remotion / 写 Remotion 的人与 AI。新视频只写 `shots.ts` 数据，**不写坐标**。  
> 代码：`src/style/`（grid / tokens / layouts / components / archetypes / types），示例：`src/demo/`。

## 0. 核心原则
1. **背景铺满、元素浮上**：每镜都有相关实景背景（视频或图，压暗 0.4–0.6，可模糊），上面叠 MG。
2. **不全是大玻璃卡**：一屏最多 1–2 张「重」玻璃卡；优先用裸数字、时间轴、细行、引用号、进度环、软提示条、浮动标签、下划线等轻量元素。大小元素穿插，禁止十镜同构。
3. **严格网格**：左右边必须落在 12 栏栏线上，内容块间距 ≥24px，**禁止重叠**。页眉三行（栏目/标题/示例标注）之间允许 8px。
4. **不要装饰框**：禁止金色 L 形角标、聚焦框、外发光框。质感靠玻璃底、细描边、内高光、投影。
5. **一屏一件事**：正在讲的那项最大、最亮；金色面积全屏 ≤8%。
6. **安全区**：底部 180px 字幕禁区；右侧约 15% 留给抖音按钮。
7. **素材规则（学员版）**：
   - **禁止**依赖本地剪映 / Mac 私有素材。
   - 城市航拍等视频放在 `public/media/stock/`，来源写进 `stock/SOURCES.md`（Mixkit / Coverr 等可商用免费授权）。
   - 关键概念用 `GenerateImage` 生成，放 `public/media/gen/`。
   - **一片一用**：同一条片子里，背景和插画的视频、图片同一个文件只能出现一次（背景与框内都算，换 trim 也不行）。`npm run check` 对重复 `src` 报错。
8. **数字标示例**：示例数据必须显示 `ExampleMark`（片尾除外）。

## 1. 网格（grid.ts）
| 项 | 值 |
|---|---|
| 画布 | 1920×1080 @30fps |
| SAFE.left / right | 96 / 1632 |
| 字幕禁区 | y ≥ 900 |
| 栏 | 12 栏；栏宽 106；间距 24；步长 130 |
| 栏目行 | y 56，高 36 |
| 标题行 | y 100，高 100 |
| 内容区 | y 232–880（高 648） |

API：`cols(c,n)` · `splitRows(y,H,parts)` · `rect(c,n,row)` · `FULL`。

## 2. 色彩 / 字体 / 动效令牌（tokens.ts）
- **COLOR**：ink `#121110` · warm `#F4EEE4` · gold `#D9B26F` / goldHi `#F3D79E` / goldDeep `#9C7536` · coral `#E0715C`（风险）· green `#8DB89A`（利好）
- **FONT**：标题 `PuHui` · 正文 `Health` · 数字 `ArialB`
- **TYPE**：kicker 28 · title 80 · heroTitle 100 · number 150 · cardTitle 44 · cardNum 72 · body 30 · label 26 · chip 24（正文 ≥24）
- **MOTION**（帧@30fps）：enter 20 · stagger 6 · chip 14 · count 30 · freeze 30 · maxShift 36
- 重点词用 `{…}`，由 `GoldText` 渲成金色

## 3. 组件 API（components.tsx）

### 3.1 基础
| 组件 | 用途 |
|---|---|
| `GlassCard` | 玻璃卡（少用）。tone: dark/pearl/gold/coral/ghost |
| `MediaFrame` | 图/视频框；`soft` 去描边更轻。描边在内侧 |
| `Chip` / `Badge` / `Count` / `Bar` | 标签、序号、滚数、对比条 |
| `Kicker` / `Headline` / `ExampleMark` / `Backdrop` | 页眉与背景 |

### 3.2 轻量 MG（优先用这些打破「全是卡」）
| 组件 | 用途 | 典型入场 |
|---|---|---|
| `BareNumber` | 无卡底大数字 | up |
| `SplitType` | 双行分裂大标题 + 下划线 | 错落入场 |
| `UnderlineDraw` | 金色下划线描画 | wipe |
| `FloatLabel` | 浮动小标签（可轻微浮动） | fade |
| `Timeline` | 横向节点 + 连接线进度 | stagger |
| `IconRow` | 图标/序号 + 标题细行（非卡） | right |
| `QuoteBlock` | 大引号 + 引文 | blur |
| `SoftCallout` | 软发光提示条（比玻璃卡轻） | scale |
| `ProgressRing` | SVG 进度环 | draw |
| `ArrowConnector` | 箭头连接 | wipe |
| `HighlightBar` | 焦点竖条 | grow |
| `StatPill` | 紧凑统计胶囊（小卡） | up |

入场 `Enter`：`up | left | right | scale | fade | blur | none`。  
Chip 放进横向居中行时外包 `<div style={{flexShrink:0}}>`。

## 4. 版式（layouts.ts + archetypes.tsx）
`layoutRects(name, n)` 只返回矩形；`ShotView` 按 `layout` 选渲染器。

| 版式 | 视觉性格 | 元素 |
|---|---|---|
| `titleFloat` | 开场：大字 + 小插图，几乎无重卡 | SplitType · chips · soft MediaFrame · SoftCallout |
| `bareNumber` | 核心数字：裸数字 + 概念图 | BareNumber · Underline · chips · soft MediaFrame |
| `splitVs` | 左右对比 | 双 MediaFrame · Arrow · 双 BareNumber · FloatLabel |
| `timeline` | 流程：无卡 | Timeline 节点 · SoftCallout 结论 |
| `mediaRows` | 一图多行 | MediaFrame · IconRow 列表（焦点接力） |
| `quoteStack` | 避坑清单 | QuoteBlock · IconRow · SoftCallout(coral) |
| `ringFeature` | 月供等比例概念 | MediaFrame · ProgressRing · 2× StatPill |
| `waitVs` | 等待对比 | 双 Media · HighlightBar · BareNumber · Arrow |
| `triadSoft` | 总结三列 | 3× StatPill（中列高亮）· SoftCallout |
| `outroAir` | 片尾留白 | 小角色 + 稀疏文案，中间空一栏，禁止堆标签 |

新增版式：① layouts 只用 rect/splitRows ② archetypes 写渲染器 ③ 跑检查脚本。

## 5. 镜头数据（shots.ts）
```ts
{id:'S04', layout:'timeline', sec:6.5, kicker:'…', title:'房贷审批，{四步}走完',
 bg:{src:'media/stock/….mp4', video:true, dark:0.58},
 data:{steps:[{t,s,chip}], note:{t}}}
```
路径约定：`media/stock/*` 航拍 · `media/gen/*` 概念图 · `media/xiaoteng.png` 角色。  
各版式 `data` 字段以 `src/demo/shots.ts` 为准。

## 6. 动画时序
- 入场 20 帧 ease-out；位移 ≤36px；缩放 0.94–1.04；可 blur/fade，不翻转不弹跳。
- 顺序：页眉 → 主元素 → stagger 6 帧依次出现。
- 焦点接力（timeline / IconRow）：约第 24 帧到 dur−60，当前项最亮。
- 结论条：dur−56 左右出现。
- 每镜最后 30 帧定格（`Freeze`）；镜间用 8–15 帧低调转场（见 §9），无声。
- 每镜 5–7 秒；整片约 60 秒、约 10 镜；**相邻镜版式不得相同**。

## 7. 素材
见 `public/media/stock/SOURCES.md`。下载优先 Mixkit / Coverr / Pexels（Pexels 若 Cloudflare 拦 curl，可用浏览器或换 Mixkit CDN）。生成图用 `GenerateImage`，16:9，无字。

## 8. 出片检查清单
1. `node --no-warnings scripts/check-layout.mjs` → 越界 / 间距≥24 / 栏线 / 素材不复用  
2. `npm run stills` → `out/联系表.png`  
3. 人眼：无截字、无角标、不全是大卡、片尾留白、字幕区与右侧按钮区空、金色 ≤8%、版式有变化  
4. `npx remotion render src/index.ts Style50-Demo out/….mp4 --muted --browser-executable=…/浏览器.sh`

## 9. 终版（v3）新增硬规则
### 9.1 城市中立
- 文案、组件、样片中不得出现任何城市名；城市只能写在镜头的可选字段 `city`（如 `city: '长沙'`）。设了 city 时 kicker 自动加前缀，不设则不显示。
- check-layout 会用正则扫描 `city` 字段以外的城市名。
- 背景素材可能拍到真实城市的天际线，学员可以按自己的城市替换素材。

### 9.2 字号下限（tokens.ts `MIN_FONT`）
- 正文 / 说明文字（`data-role="body"`）≥ 34px；标签、chip、kicker ≥ 26px。
- 当前令牌：kicker 30、title 80、heroTitle 92、number 150、quote 60、rowTitle 40、body 34、label 28、chip 28、ringValue 52。

### 9.3 留白与填充率
- 带 `data-fit` 的容器（chip、pill、callout）里，文字宽度不超过容器宽度的 75%（`RULE.fillMax`）。
- 多行文字行高 ≥ 1.3（`RULE.lineHeight`）。
- 不允许溢出。所有文字必须落在 layoutRects 给出的版式区内（容差 ±6px）。装饰性字形加 `data-deco` 可以跳过检查。

### 9.4 组间距
- 独立的 MG 组之间至少相隔 48px（`MG_GAP`）：横向隔一个空栏，纵向用 `splitRows` 留 48px。只有连接件（`conn*`）可以放宽到 24px。
- 内容区从 contentTop 248 开始，高度 632。

### 9.5 片尾（outroAir）
- 片尾内容由镜头数据驱动：`OutroData = {eyebrow, line, cta, account?, character?}`。
- `character` 默认不填，此时文字整体居中（rect 2–8 栏）。填了角色图时，角色占 0–3 栏，文字占 5–11 栏。不要在模板里写死任何人物（例如小滕）。

### 9.6 转场（替代硬切）
| 序号 | 类型 | 帧数 | 做法 |
|---|---|---|---|
| 1 | pushBlur | 12 | 新镜头带轻微模糊推入，旧镜头推出并淡出 |
| 2 | crossfade | 10 | 叠化 |
| 3 | maskWipe | 14 | 柔边遮罩擦除 |
| 4 | lightSweep | 12 | 柔光扫过后切入 |
| 5 | goldCut | 11 | 金线从左扫到右，只发生在切镜的这几帧 |
- 上表五种转场按顺序轮换（transitions.tsx）。实现方式是用重叠的 Sequence：旧镜头保持定格并延长 T 帧，总时长不变。不要使用花哨的转场，也不要借转场把背景长期糊住。

### 9.7 亮度
- 背景遮罩 = max(0.22, dark − 0.16)，滤镜为 `brightness(1.1) saturate(1.05)`，上下各有一层渐变压暗以保证文字对比。COLOR.sub 的不透明度为 0.78。
- 按时段设 `bg.dark`：白天航拍 0.38–0.45（实际压暗 0.22–0.29），黄昏或阴天 0.45–0.52，夜景 0.52–0.60，静图背景 0.45–0.55。背景默认不糊，`blur` 必须为 0（视频同样禁止）。天空过曝就换 trim 或把 dark 提高约 0.05。文字靠压暗、渐变和前景底衬。详见 `素材与生图规则.md` 的 C 部分。

### 9.8 检查命令
- `npm run check`：静态检查，包括贴栏线、组距、素材不复用、城市名、字号令牌。
- `npm run stills`：静态检查加 DOM 检查（用 @remotion/renderer 打开 onBrowserLog，读取每镜定格帧的 `CHECK|id|[...]`），同时输出 `out/stills/*.png` 和 `out/联系表.png`。只有全部 ✓ 才能出片。

### 9.9 防「顿一下」（4.5 修复）
- 镜头末尾 1 秒的定格**只冻结前景**（文字和 MG）。背景视频和媒体框里的视频继续播放：`LiveFrameCtx` 记录真实帧，`LiveVideo` 用 `<Freeze frame={真实帧}>` 跳出外层的定格。
- 静态图背景按真实帧缓慢推近（`scale 1.02 → +0.0003/帧`），所以静图镜头也不会停住。
- 每个 Sequence 都设 `premountFor={30}`，提前 1 秒挂载下一镜，Studio 预览时不会因为加载而卡一下。
- 视频素材时长必须 ≥ trim + 镜长 + 0.5s（转场时旧镜头还要多播 T 帧）。素材太短时，末尾会停在最后一帧，`npm run check` 会报错。
- 验收方法：对成片逐帧求亮度差（ffmpeg `signalstats` 的 YDIF），**不能出现连续 ≥2 帧差值为 0** 的情况。24/25fps 素材每 4–6 帧会有 1 帧重复，这是帧率换算造成的，属于正常现象。
